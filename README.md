# Takachi cable gland 3D models (unofficial)

English | [日本語](README.ja.md)

STEP models of TAKACHI cable glands for which only 2D drawings are published.
Use them to check fit and to design mounting holes and panel layouts.
Each model was checked against the official drawings.

> [!IMPORTANT]
> **Unofficial.** Not affiliated with or endorsed by TAKACHI. Made only from the 2D drawings on takachi-el.co.jp.
> No warranty: check any dimension that matters for mounting or fit on a real product. Details: [NOTICE.md](NOTICE.md)

## Usage

Pick a model below and download the STEP file for your color.

Each file is an assembly of separate parts, in mm.
The origin is on the axis at the outer face of the panel; +Z points to the cap side and the thread runs toward -Z.
Revisions are in [manifest.json](manifest.json); changes are in [CHANGELOG.md](CHANGELOG.md).
